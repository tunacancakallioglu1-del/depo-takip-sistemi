# depo-takip-sistemi

Depo Operasyon Yönetim Sistemi (v2) - ürün, sipariş, iade, raporlama ve audit log modülleriyle genişletilmiş web tabanlı takip sistemi.

## Yeni Modüller
- Ürün Yönetimi (`/urunler`)
- Sipariş Yönetimi ve Excel yükleme (`/siparisler`)
- İade Yönetimi ve Excel yükleme (`/iadeler`)
- Raporlama API + Excel export (`/raporlar`)
- Audit Log (`/audit-log`)
- Dashboard (`/`)
